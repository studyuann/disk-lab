# CrystalDiskInfo 사진 -> 디스크 관리대장 변환기 (Disk Ledger AI)

CrystalDiskInfo 결과 스크린샷 이미지를 드래그&드롭하면 AI Vision이 주요 S.M.A.R.T 정보와 디스크 스펙을 자동으로 판독하여 **엑셀(.xlsx) 디스크 관리대장**으로 자동 변환해 주는 프로그램입니다.

---

## 🌟 주요 특징 및 지원 사양

1. **완벽한 이미지 인식 (AI Vision)**
   - 배경 일러스트가 들어간 시즈쿠/쿠레이 에디션, 다크 모드, 표준 테마 모두 지원
   - 한글/영문 UI 및 16진수 원시 값(Raw Values) 정밀 변환

2. **자동 추출 및 분석 항목**
   - **기본 사양**: 모델명, 용량, 일련번호(S/N), 펌웨어, 인터페이스, 전송 모드, 드라이브 문자, 회전 속도(RPM)
   - **운영 지표**: 사용 횟수, 사용 시간 (시간 및 년/일 자동 환산), 현재 온도, 건강 상태
   - **S.M.A.R.T 핵심 위험 지표**:
     - **05** 재할당된 섹터 수 (Reallocated Sectors)
     - **C5** 보류 중인 섹터 수 (Current Pending Sectors)
     - **C6** 회복 불가능 섹터 수 (Uncorrectable Sectors)
     - **C7** 울트라 DMA CRC 오류 횟수 (케이블 불량 이력)
     - **01** 읽기 오류율

3. **스마트 엑셀 관리대장 (`.xlsx`)**
   - **조건부 위험 경고 서식**: 05, C5, C6 섹터 오류 발생 시 해당 행 전체 **연빨강 배경 + 붉은 글씨** 자동 강조
   - **주의 경고 서식**: CRC 오류(C7) 또는 고온(50°C 이상) 발생 시 **연노랑 배경** 자동 강조
   - **중복 일련번호(S/N) 처리 옵션**:
     - *기존 갱신(Update)*: 동일 디스크가 다시 들어오면 최신 상태로 갱신
     - *이력 추가(Append)*: 시간 경과에 따른 디스크 상태 변화를 행으로 누적 기록
   - **기존 엑셀 대장 불러오기 지원**: 기존에 사용하던 대장 엑셀을 업로드하면 내용을 그대로 유지하면서 새 디스크 추가 가능

## 🚀 빠른 시작 (실행 방법)

### 방법 1. 간편 실행 (가장 추천)
폴더에 있는 **`실행하기.bat`** 파일을 더블 클릭합니다.
- 로컬 웹 서버가 구동되고 웹 브라우저(`http://localhost:3000`)가 자동으로 열립니다.

### 방법 2. 터미널 실행
```bash
npm start
```
웹 브라우저에서 `http://localhost:3000`으로 접속합니다.

## 🖥️ 웹 대시보드 사용 흐름

1. **API 키 설정 (최초 1회)**
   - 웹 화면 우측 상단의 **[API 설정]** 버튼 클릭
   - 사용할 AI 엔진 선택: **Anthropic Claude (권장)** / **Google Gemini** / **OpenAI**
   - 해당 API 키 입력 후 저장 (브라우저 로컬스토리지에만 안전하게 저장됨)
   - *팁: API 키 없이도 상단 **[샘플 데이터 체험]** 버튼을 누르면 즉시 변환 결과와 엑셀 다운로드를 테스트할 수 있습니다.*

2. **스크린샷 업로드**
   - 크리스탈인포 캡처 이미지를 브라우저 중앙 점선 영역에 **드래그 & 드롭** (여러 장 또는 폴더 통째로 드래그 가능)
   - 또는 **[사진 파일 선택]** / **[폴더 선택]** 버튼 클릭

3. **관리대장 확인 및 엑셀 다운로드**
   - 분석 결과가 즉시 대시보드 표에 실시간으로 표시됩니다.
   - 썸네일을 클릭하면 원본 스크린샷과 바로 대조할 수 있습니다.
   - **[엑셀 다운로드 (.xlsx)]** 버튼을 누르면 조건부 색상이 입혀진 실무용 엑셀 파일이 즉시 다운로드됩니다.
   - **[대장 파일 저장]** 버튼을 누르면 현재 작업 폴더의 `디스크관리대장.xlsx` 파일에 바로 동기화 저장됩니다.

## ⌨️ CLI (명령줄) 일괄 변환 도구

웹 화면 없이 터미널에서 스크린샷 폴더를 바로 엑셀로 변환하고 싶을 때 사용합니다:

```bash
# 기본 사용 (screenshots 폴더 내 모든 이미지를 디스크관리대장.xlsx로 변환)
node scan.js ./screenshots -o ./디스크관리대장.xlsx -k <API키>

# Claude 엔진 사용 예시
node scan.js ./screenshots -p claude -k sk-ant-...

# 기존 대장 엑셀에 새 이력으로 누적(append)하기
node scan.js ./screenshots -s append -k sk-ant-...

# API 키 없이 샘플 데이터로 엑셀 생성 테스트
node scan.js --sample
```
